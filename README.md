# FRLG RNG Assist 0.4.0

PokeLDN 的独立第三方插件：设置 RNG advances 范围与筛选条件，在掌机显示 seed / 倒计时，到点触发一次按键。你自行到决定点；**凤王按 ↑，其余目标按 A**。无需按住 B，不检测站位、朝向、目标对象或脚本等待。

这是实机测试版；软件检查不代表新增目标的时序已在掌机验证。交付检查见 [验证记录](docs/VALIDATION.md)，操作见 [测试步骤](docs/HARDWARE_TEST_ZH.md)。

## 这版变化

- 增加定点、礼物、化石、游戏厅、游走个体初始化，以及野生甜甜香气、三种钓竿、碎岩和未知图腾配置。
- 已知参考 Offset 直接预填；每个目标分别记忆。代欧奇希斯等较大值也能填写，上限 65533。
- 甜甜香气等菜单配置在队伍菜单里继续显示和计数，通过菜单回调注入一次 A。
- 野生使用 FRLG 的 H1 / H2 / H4 模型，计入性格与 PID 重抽；未知图腾另外处理房间字母与 PID 顺序。
- 凤王注入 ↑ 的单次方向输入，供向上走入事件格使用。

## 安装

使用 PokeLDN v0.39.1 / API 1.11，Plugins → Add a plugin，选择 frlg-rng-assist-0.4.0.pokeplugin。已有旧版可从插件卡片更新文件。Games → FireRed & LeafGreen → **RNG：搜索与到点按键**。

目前仅支持 Switch 英文 / 法文 rev 0A：BPRE、BPGE、BPRF、BPGF。Wireless 1.8.0 无需因为本插件更换。包内附有源码、构建脚本及预编译资源，用户不需要 Python 或 ARM 编译器。

## 一次尝试

1. 先保存，完全重新启动游戏以清除旧注入。查看 L / L+R 前将 OPTIONS → BUTTON MODE 设为 L/R 并保存。
2. PC 选目标、范围和条件。首测打开允许非闪光，性格 / IV 不限；确认 Offset 预填值，勾选安装并启用到点按键。
3. PC 点 Start，掌机 Mystery Gift → Wonder Cards → Friend → POKELDN，等待安装回执 0x524E4703。
4. 正常退出到标题并继续游戏。插件从标题实际初始 seed 起算，不使用 Mystery Gift 会话的 seed。进入地图时 advances 通常已经大于 0。
5. 自行停在目标的最后决定点，松开按键等待倒计时。甜甜香气停在队伍菜单的该选项；钓鱼自行完成前面的轮次并停在最后确认；凤王停在触发格南侧、朝上，等待 ↑。
6. 观察实际是否触发，再核对捕获结果。发送一次按键后本轮结束；软重启或关闭游戏会清除注入，下一轮需重新安装。

没有自动走路、打开菜单、反复钓鱼或连续确认。御三家有参考配置，但新存档正常流程在选御三家前无法进入 Mystery Gift；本插件不提供提前解锁或跨新游戏保留。

## Offset 与搜索模型

Offset 单位是 RNG advances，不是画面帧或秒。在原基础提前量上增加：超梦基础 1，定点 / 三鸟基础 2，野生基础 1。界面填写的是**额外**提前量；急冻鸟默认填 3，合计提前 5，不用填 5。超梦默认填 2，合计提前 3。

其他参考预填包括御三家 / 鲤鱼王 / 卡比兽 / 波克比 / 游走初始化 / 化石 / 游戏厅 3、伊布 4、道场 6、引梦貘人 86、代欧奇希斯 501、洛奇亚 277、凤王 379。顽皮雷弹、拉普拉斯、自定目标及野生默认 0，需校准。

这些新增数字沿用用户提供的参考表，**没有把其画面帧数换算成实测 advances**，也未验证每个最后决定点；实际延迟可能不同。若多次结果稳定晚 1 advance，Offset 加 1；稳定早 1 则减 1，然后重新启动并注入。甜香 / 钓鱼动画、当前场景和无线推进也要纳入校准。

范围包含端点，最大 9999999，以标题实际初始 seed 为 0：定点对应首次 PID 抽取前；野生对应遭遇槽位抽取前，之后还有等级、性格及 PID 重抽。离线工具选择相同模型与边界。默认 Method 1 / H1，可改 2 / H2 或 4 / H4；未知图腾需选正确房间。野生目前筛选闪光、性格和 IV，不筛物种或槽位；遇见已生成的游走宝可梦不属于新的野生生成。

## 掌机显示

上排为 8 位十六进制当前 seed，下排为状态字母和 7 位十进制数。

| 下排 | 含义 |
|---|---|
| Axxxxxxx | 搜索中；数字为搜索位置 |
| Bxxxxxxx | 到按键时机的剩余 advances；黄色奇偶不一致，绿色一致且回调可用 |
| C0000001 | 已排定按键，等待本轮回调 |
| C0000000 | 已发送一次按键；凤王 ↑，其余 A，不单独证明生成时序 |
| D00000xx | 红色原因码，保留约 1 秒后在原范围续搜 |
| E0000000 | 原范围耗尽，本轮结束 |
| F0000000 | 初始 seed 改变、回退或超出计数范围，本轮结束 |

B 一旦显示就保留目标，颜色变化不提前换目标。实际错过才提示并续搜，不补按过期目标、不扩大范围；一次成功发送后不再续搜。

按住 L 查看初始 seed 与绝对 advances；同时按住 L+R 查看当前队尾完整 PID（白色）与队伍位置 1..6。松开恢复，单按 R 不切换显示。空队伍 / 数量异常显示 FFFFFFFF / 00000000。查看不暂停计数或按键，隐藏的 D 提示等松开后计时。本插件不单独读取 ZL / ZR。

地图配置只在地图绘制；甜香、钓鱼、未知图腾及御三家配置在菜单也绘制和运行，均须先回地图建立实际 seed。野生菜单配置到点就会尝试发送，不识别当前菜单是否为你想要的决定点；不要在不准备触发时停留在其他菜单。已识别的战斗回调不发送。

| D 原因码 | 条件 |
|---|---|
| 04 | 当前回调不可用，或排定后的场景回调改变 |
| 09 | 已越过按键时机 |
| 10 | 时刻到达但主循环仍忙 |
| 11 | 回调前 RNG 不符合预期的一次无线推进 |
| 12 | 排定的按键回调过期 |

旧 03 / 05 等对象、脚本门槛已移除。地图配置在教学电视中错过时，回到地图后再显示红色 D09 约一秒并续搜；电视中的时间不消耗提示。菜单配置在可运行菜单里也会显示提示并计时。

## 结果核对与离线工具

捕获后放入队伍并在游戏里保存，再运行「核对捕获结果」。指定种类默认选择唯一同种目标；未限定种类的野生 / 自定默认选队尾，也可指定 1..6。支持导入 .pk3 / .ek3 或 608 字节队伍 dump。关联安装报告可继承筛选、Method、房间及范围；加上实际初始 seed 可检查生成 advance。记录符合条件不单独证明输入的实际时序或捕获来源。固定 PID 的 NPC 交换、遗传蛋不属于这些标准随机模型。

离线搜索支持定点 Method 1/2/4、野生 H1/H2/H4 和未知图腾；PID / IV 反推工具仍为定点模型，野生捕获核对会另外恢复可能的遭遇起点。IV 顺序统一为 HP、攻击、防御、特攻、特防、速度。

报告和采集保存在 PokeLDN 的 FRLG RNG Assist 资料库；指定文件名不会覆盖已有文件。安装失败不会写成安装成功。插件不写 RNG、PID、IV、存档或 ROM；临时输入与显示使用现有 2200 字节驻留区，不能叠加其他 resident hooks。

## 开发

源码仓库：[axechaso/frlg-rng-assist](https://github.com/axechaso/frlg-rng-assist)。插件独立开发和分发。开发环境为 Python 3.13，宿主固定 v0.39.1 / 4780dcaeac52479e6212483009f64f348581d7cc。每次推送由 GitHub Actions 检查并生成测试包。

    python -m pip install -r requirements-dev.txt
    $env:POKELDN_SOURCE = 'D:\path\to\pokeldn-v0.39.1'
    python -m ruff check .
    python -m pytest -q

重新编译需 GNU Arm Embedded GCC 15.2.1，ARM_TOOLCHAIN 指向以目录分隔符结尾的工具前缀：

    python scripts/build_guest.py
    python scripts/build_guest.py --check
    python D:\path\to\pokeldn-v0.39.1\scripts\pack_plugin.py . -o dist\frlg-rng-assist-0.4.0.pokeplugin
