# 0.7.3 实机测试

使用 frlg-rng-assist-0.7.3.pokeplugin，支持 PokeLDN v0.39.1 / API 1.11、Switch 英文 / 法文 rev 0A 火红 / 叶绿。以下是待完成的实机步骤，软件回归不代表这些步骤已经通过。

## 本次新增：生成后捕获

1. 先更新插件。新一轮注入前勾选「预载出闪后的捕获搜索」（默认打开）；捕获 Offset 下限先用参考值 241，上限留空。已有旧版 RAM 注入必须重新安装新注入；不要为升级而退出正在保留的闪光战斗。
2. **普通轮先验收**：允许非闪光、物种 / 性格 / IV 不限，按原流程安装并触发遭遇。PC 安装会话已结束应不影响后续操作。不退出战斗或 Mystery Gift，不重置 seed。
3. 手动选择球，停在最后一次 **使用 / Use** 确认处。按住 R，点一次 SELECT，松开两键。下排应变成 **8 搜索 / 9 倒计时**；正常上排仍为当前 seed。L / R / L+R 页面松开后应恢复倒计时。
4. 首先验取消：倒计时中再按一次 R＋SELECT，应显示 E，等待时不能投球。再次按同一组合应重新搜索。不要保持 SELECT 以代替再次点按。
5. 在正确确认处等到计时结束，应只投一球；捕获搜索会优先选连续成功段中心，三连成功时应选中间候选。9 的绿色 / 黄色只显示当前奇偶，必要时手动调整。C 表示输入已发送，不能用 C 单独判定捕获成功。红色 D 应保留约一秒后恢复 8 / 9，不补按已错过的目标。E 表示取消或范围耗尽；F 表示计数失效。
6. 记录球种、HP / 状态、捕获 Offset 上下限、是否确实投球、实际捕获结果。精灵球阈值为 16643，高级球阈值为 19784。原 Python 模型已验证；**241 不是本插件已验证的按键时序**。用原工具的捕获采样核对实际落点并校准投球 Offset，不把生成 Offset 的误差重复加进捕获轴。
7. 正常投球和 Offset 经重复普通轮确认后，闪光轮固定同一捕获 Offset。范围上下限不同意味着所有可能起点都必须四次成功，可能等待更久。不要把旧 SysBot 的 242～245 直接当作插件的已验证值。
8. 凤王额外检查：生成应按 ↑，捕获倒计时结束应按 A。甜香 / 钓鱼 / 未知图腾也应能在生成结束后进入相同捕获流程。狩猎地带不使用普通背包 Use 的捕获流程，不在此功能适用范围。

## 安装和选择

1. 在 Plugins 更新到 0.7.3 并重启宿主。Games → FireRed & LeafGreen 应只看到「RNG：搜索与到点按键」和「RNG：PID 反查实际命中」。
2. 选择前者。先选择游戏与类别，再选目标；定点只能选 Method 1 / 4。选择野生后应显示遭遇方式、地点及 H1 / H2 / H4。
3. 目标 / 地点后显示预设 Offset，野生两列依次为火红 / 叶绿。手动 Offset 留空自动采用预设。测试狩猎地带切换游戏，应为 256 / 257；发电厂应为 256 / 263。没有资料的野生地点为 256。
4. 切换 App language 为中文 / 日文 / 英文并重启宿主，两项工具的标题、字段、地点、物种、性格和正常输出应随之变化；游戏版本和输入的数值保持不变。其他宿主语言使用英文。

## 野生筛选验收

1. 首轮选常青森林、甜香草地 / 洞窟、皮卡丘、允许非闪光、性格及 IV 不限，先核对物种和 Offset。选择具体楼层 / 区域，不用合并地点；R / L+R 读取实际结果，手动 PID 反查时保留相同地点及物种。
2. 比较火红 / 叶绿限定种。例如火红发电厂电击兽可安装，同样条件改为叶绿应在安装前拒绝，不能注入一个永远不匹配的假配置。没有该钓竿或水面遭遇的地点也应拒绝对应物种。
3. 基础时序确认后逐项增加性格、IV 下限 / 上限，再打开闪光筛选。可先测试特攻 / 速度下限 `0,0,0,25,0,25`；抓到后用 R 核对。不要首次就叠加全 31 与闪光，范围耗尽不是自动输入故障。
4. 钓鱼各钓竿独立验收；未知图腾走独立类别。变幻洞窟事件表必须与游戏相同。普通野生模型不覆盖游走个体替代甜香的情况。

## 一次按键和显示

1. 掌机在目标附近保存，OPTIONS → BUTTON MODE 设为 L/R，完全重启以清除旧注入。
2. 初测范围 10000..200000，允许非闪光，性格 / IV 不限。勾选启用到点按键。
3. PC 点 Start，掌机 Mystery Gift → Wonder Cards → Friend → POKELDN。必须等日志确认回执 0x524E4703。
4. 退出至标题再继续。普通上排为当前 seed，下排 A 搜索 / B 倒计时；按 L 记下初始 seed。
5. 自行到最后决定点。三鸟在面前；超梦停在对话末等待按键；甜香停在队伍菜单该选项；钓鱼自行完成前面的轮次；凤王停在触发格南边相邻一格、朝上。
6. 松开按键等待。绿色表示按键时机奇偶一致，黄色表示不同。C0000000 表示发出一次输入；观察是否真的进入事件 / 遭遇。
7. 错过应先显示红色 D 约 1 秒，再变 A 续搜。教学电视中错过的地图目标应在回到地图后显示提示；E / F 为终止状态。

一次输入后不再自动尝试下一只；软重启和关闭游戏清除注入，下一轮需重新安装。不要在倒计时即将结束时停在无关菜单。

## R 个体值和觉醒力量

捕获后让目标留在队尾，返回可显示覆盖层的画面：

- **R**：上排每两位依次为 HP、攻击、防御、速度；下排为特攻、特防、觉醒属性编号、威力，均为十进制。
- **L+R**：上排完整十六进制 PID，下排队尾位置 1..6。
- **L**：初始 seed / 绝对 advances；松开恢复普通显示。

全 31 的例子是 31313131 / 31311670，即觉醒恶 70。属性编号：01 格斗、02 飞行、03 毒、04 地面、05 岩石、06 虫、07 幽灵、08 钢、09 火、10 水、11 草、12 电、13 超能、14 冰、15 龙、16 恶。

交换队尾或修改队伍数量后，R / L+R 应显示当前队尾，不依赖保存。R 无有效记录为 FFFFFFFF / FFFFFFFF；L+R 空队伍为 FFFFFFFF / 00000000。按键查看不暂停计数或到点输入，隐藏的 D 提示松开后继续。

## 手填 PID 反查

1. 打开第二个工具，用户**手动填写**本轮初始 seed、实际 PID（十六进制）。
2. 类别、目标、方式与实机一致，范围包含这次实际 advances。无需神秘礼物会话、密钥或六项 IV。
3. 可填原目标 advance、原手动 Offset，查看误差和建议 Offset。默认预设不曾覆盖时，手动 Offset 继续留空即可。
4. 已知例子：C76F / 4762A09B / 急冻鸟 → 3354；原目标 3351、额外 Offset 3 → 差值 +3、建议 Offset 6。
5. 野生若有多个遭遇起点，缩小范围并对照 R 的实际 IV。反查报告的 IV / 觉醒力量是预测值。

保留实际 seed、目标 advance、实际 PID、R 显示、按键结束状态和安装报告，才能继续校准。不同触发方式和场景的参考 Offset 仍需实测。
