# FRLG RNG Assist 0.4.0 实机测试

统一流程：你到决定点，插件搜索、倒计时并触发一次。**凤王是 ↑，其他是 A**。无需按 B，也没有站位检测。新增配置与 Offset 仍需实机校准。

## 1. 更新与设置

1. Plugins 更新为 frlg-rng-assist-0.4.0.pokeplugin。PokeLDN 使用 v0.39.1 / API 1.11，Wireless 1.8.0 无需另刷。
2. 完全重新启动游戏，清除旧注入；不要叠加 boosts。先在附近保存，队伍留空位。OPTIONS → BUTTON MODE 设为 L/R 并保存，方便查看 seed / PID。
3. 打开「RNG：搜索与到点按键」，选目标；每个目标显示自己的额外 Offset，修改值分别保存。
4. 起始 advance 10000、结束 200000；赶路时间长则增加起点。首轮允许非闪光，性格不限，IV 为全范围；启用到点按键，关闭仅预览。
5. 定点一般 Method 1，野生一般 H1。未知图腾选择实际房间。

Offset 为额外 advances。急冻鸟默认 3（总提前 5），超梦 2（总提前 3）；其他参考已预填，例如代欧奇希斯 501、洛奇亚 277、凤王 379。野生 / 未知延迟默认 0，先实测再调。参考表的“Frames”并不自动等于实机 RNG advances，不能仅凭预填数字认定已经校准。

## 2. 注入

PC Start；掌机 Mystery Gift → Wonder Cards → Friend → POKELDN。等待安装回执 0x524E4703，再退出到标题，选择继续游戏。正常返回标题保留临时程序；软重启或关闭游戏会清除，需要重新注入。

回到地图先建立本次实际初始 seed，出现上排 current seed 与下排 A 搜索 / B 倒计时。按 L 记初始 seed 和绝对 advances。按 L+R 可看队尾 PID 与位置；查看不暂停倒计时。进入地图不归零。

## 3. 到决定点等待

| 目标 | 你停的位置 | 插件按键 |
|---|---|---|
| 三鸟 / 洛奇亚 / 顽皮雷弹等 | 已到想要触发的位置 | A |
| 超梦 | 叫声和文字结束后的按键等待 | A |
| 礼物 / 购买 / 化石 / 游戏厅 | 生成前的最后一次确认 | A |
| 凤王 | 触发格南侧相邻一格，朝上 | ↑ 一次，供向上走一步 |
| 甜甜香气 | 队伍菜单的甜甜香气选项 | A |
| 钓鱼 | 自行完成前面的钓鱼轮次，停在最后确认 | A |
| 碎岩 | 使用技能前最后一次 A 确认 | A |
| 未知图腾 | 对应房间，甜甜香气选项 | A |

甜香等菜单配置在队伍菜单内也应继续显示和倒计时。请记录有没有显示、是否继续计数、到点是否实际执行技能。插件不会打开菜单、自动完成钓鱼轮次，或验证你是否停在正确决定点。不要在等待时切到无关菜单。

御三家有模型 / Offset 配置，但正常新存档在选御三家前不能进 Mystery Gift；本插件没有解决提前注入入口。游走配置针对个体第一次初始化，后续在野外遇见它不重新生成个体。

## 4. 观察结果

- B 的绿色只表示与按键时机奇偶一致且回调可用；黄色表示不一致，不会因此提前丢弃目标。
- C0000001 为已排定，C0000000 为已发送一次。凤王应当向上走一步，其余应当完成 A 的动作；实际是否触发才是观察结果。
- 错过或失败先红色 D 约一秒，再原范围续搜。D09 越过时机，D10 主循环忙，D11 回调前推进不符，D12 按键回调过期，D04 回调不可用或场景改变。
- 地图配置在教学电视里超过目标时，应返回地图后先提示 D09 再续搜。菜单配置在可运行的菜单里也计提示时间。
- E 为范围耗尽，F 为计数失效。成功发送一次后也会停止；需要另一轮时完全重启并重新安装。

## 5. 校准并核对

先允许非闪光确认按钮动作，再用实际初始 seed、相同模型 / 房间及实际 PID 查对应 advance。定点的索引为首次 PID 抽取前；野生是槽位抽取前，包含后续性格 / PID 重抽，不能直接套定点 Method 1 的索引。

多次稳定晚 1 advance，额外 Offset 加 1；稳定早 1 则减 1。修改后完全重启、重新注入。若误差不稳定，记录决定点和经过的动画，不能当固定 Offset 调整。

捕获后在地图按 L+R 看队尾 PID，确认新捕获确实留在队伍；放进电脑时显示的是旧队尾。保存后用「核对捕获结果」，关联安装报告和初始 seed 可核对原范围。野生 / 自定目标默认取队尾，必要时指定位置。

回传最少信息：插件版本、游戏 / 语言、目标、Offset、模型、实际初始 seed、最后 C/D/E/F、是否实际触发、实际 PID；甜香另记队伍菜单里是否显示和计数。软件检查尚不能替代这些实机结果。
